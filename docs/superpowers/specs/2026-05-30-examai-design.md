# ExamAI — 智能试卷生成平台 设计文档

> **版本**: v1.0 | **日期**: 2026-05-30 | **状态**: 设计阶段

---

## 1. 产品愿景

面向初中教师的智能考试试卷生成平台。从网上搜集各学科试卷资源构建题库，基于教师个性化需求自动生成定制化考试试卷，以 Web 网站形式管理和运营。

**路线图：** 校内教师个人工具（MVP验证）→ 商业化SaaS付费平台

---

## 2. 目标用户

| 阶段 | 用户 | 核心场景 |
|------|------|---------|
| MVP | 3-5位种子教师（数学/物理/历史） | "我是初二物理老师，期末了，帮我出一份覆盖力学+电学的试卷" |
| 商业化 | 全国初中教师 | 付费订阅，团队协作，学校版 |

---

## 3. MVP 范围定义

### 3.1 MVP 学科

- 数学（七年级/八年级/九年级）
- 物理（八年级/九年级）
- 历史（七年级/八年级/九年级）

### 3.2 MVP 时间目标

**3-4个月**，交付可用的核心流程。

### 3.3 MVP 核心页面（6个）

| # | 页面 | 功能 | 优先级 |
|---|------|------|--------|
| 1 | 登录/注册页 | 邮箱注册、登录、找回密码 | P0 |
| 2 | 工作台首页 | 我的试卷列表、快速创建入口、使用统计 | P0 |
| 3 | 智能组卷页 | A面表单配置 + B面AI推荐 → 生成试卷 → 预览 → 换题 | P0 |
| 4 | 题库管理页 | 搜索/筛选、知识点树、手动录入、批量导入 | P0 |
| 5 | 试卷详情/导出页 | 在线预览、PDF下载、Word下载、答题卡+解析 | P0 |
| 6 | 资源采集页 | 手动上传试卷、AI解析进度、审核入库 | P1 |

### 3.4 核心用户流程

```
登录 → 工作台 → 创建试卷 → 配置组卷(AI辅助) → 预览微调 → 导出PDF/Word
```

## 4. 技术架构

### 4.1 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| 前端 | React + Ant Design | 组件库丰富，适合管理后台，组卷交互体验好 |
| 后端 | Django REST Framework | 开发效率高，Python AI生态优势 |
| 异步任务 | Celery + Redis | 爬虫/AI解析/PDF生成均为耗时任务 |
| 数据库 | PostgreSQL | 关系型数据，JSON字段支持灵活配置 |
| 缓存/队列 | Redis | 缓存 + Celery消息代理 |
| 文件存储 | 本地存储（MVP） → MinIO/S3（后期） | MVP简化，后期迁移 |
| 认证 | JWT (simplejwt) | 无状态认证，前后端分离标准方案 |

### 4.2 架构图

```
React SPA (Ant Design)  →  Django REST API  →  Celery Worker  →  PostgreSQL
        ↕                      ↕                    ↕
   浏览器缓存              Redis (缓存+队列)      MinIO (文件)
```

### 4.3 AI 能力

| AI能力 | 用途 | MVP |
|--------|------|-----|
| LLM 题目结构化解析 | 非结构化试卷文本 → 结构化题目（题干/答案/解析/题型/难度/知识点） | ✅ |
| LLM 智能组卷推荐 | 输入"初二物理期中" → 自动推荐知识点覆盖+题型+难度配置 | ✅ |
| OCR 图片识别 | 识别试卷扫描件/图片中的文字和公式 | ⏳ MVP后期 |

## 5. 数据模型

### 5.1 核心实体

```
Subject(学科) ──┐
Grade(年级)  ──┤
               ├──→ Question(题目) ←──→ KnowledgePoint(知识点树)
               │        │
               │        └──→ QuestionOption(选择题选项)
               │
               └──→ ExamPaper(试卷)
                        └──→ ExamPaperSection(分区)
                                 └──→ ExamPaperItem(题目关联)

User(用户) ──→ ExamPaper(试卷)
```

### 5.2 题目标签体系（D级全量）

每道题携带以下标签：

- **基础维度**：学科、年级、题型（选择/填空/判断/简答/计算/论述）
- **难度评估**：难度 1-5 星（1易→5难）
- **认知层级**：识记 / 理解 / 应用 / 分析 / 综合
- **知识点**：多级树形结构，多对多关联（如 物理→力学→牛顿定律→牛二律）
- **来源信息**：来源类型（真题/模拟/原创）、来源详情（"2024北京中考"）、考试类型（单元/月考/期中/期末/中考）
- **统计信息**：默认分值、预计答题时间、使用次数

### 5.3 关键设计决策

- **知识点自引用树**：通过 parent FK 支持无限层级
- **题目-知识点多对多**：一道综合题可关联多个知识点
- **试卷配置快照**：ExamPaper.config 保存组卷时的完整参数 JSON，确保可追溯可复现
- **三级试卷结构**：试卷 → Section(分区) → Item(题目)，支持标准排版

## 6. 功能模块

### 6.1 题库管理中心

- 题目列表（分页、搜索、多条件筛选）
- 题目详情与编辑
- 知识点树管理（增删改、拖拽排序）
- 批量导入（Excel模板）
- 题目审核流程（草稿→已审核→已禁用）

### 6.2 智能组卷引擎

- **A面 - 表单精细配置**：学科/年级/考试类型/知识点范围/题型分布/难度比例/总分/时长
- **B面 - AI智能推荐**：输入考试意图，AI自动推荐配置参数
- 试卷实时预览
- 手动调换题目（不满意某题可换）
- 难度分布可视化图表

### 6.3 试卷输出中心

- 在线预览（标准试卷排版）
- PDF 下载（A4排版，适合打印）
- Word 下载（可编辑，方便老师微调）
- 答题卡生成
- 参考答案 + 详细解析

### 6.4 资源采集系统

- 手动上传试卷文件（PDF/Word/图片/文本）
- AI 自动解析（LLM提取题目结构化信息）
- 解析结果审核（人工确认/修正后入库）
- 爬虫任务管理（后期）

### 6.5 用户与商业化（MVP基础）

- 注册/登录/找回密码
- 个人试卷夹（我的试卷列表）
- 使用配额管理（免费额度/付费额度）
- 后期扩展：付费订阅、团队协作、学校版

## 7. 试卷资源来源策略

| 来源 | 方式 | 阶段 |
|------|------|------|
| 淘宝/闲鱼购买 | 获取高质量PDF/Word试卷作为种子数据 | MVP |
| 网络爬虫 | 从公开教育资源站抓取试卷 | MVP+ |
| 手动上传 | 老师自行上传试卷文件 | MVP |
| 合作/API | 对接学科网、菁优网等题库（后期） | 商业化 |

---

## 8. 非功能需求

- **安全性**：JWT认证、API鉴权、敏感数据加密
- **性能**：试卷生成 3秒内完成（不含异步），题库搜索支持 10万+ 题目量
- **可用性**：响应式设计，支持PC端（主要）+ 平板端
- **可扩展性**：前后端分离，学科/知识点可配置扩展，存储可迁移至OSS

## 10. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 题库冷启动（题目太少无法组卷） | 高 | 购买种子数据 + 手动录入首批1000道核心题 |
| AI解析准确率不足 | 中 | 人工审核环节兜底，逐步优化Prompt |
| 试卷版权问题 | 中 | 仅收录公开来源，注明出处，后期可洽谈合作 |
| 3-4月时间紧张 | 中 | P1功能可降级，保证P0核心流程完整 |
